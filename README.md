# CodeAlpha – Basic Chatbot Using Python

## Project Description
A simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through the terminal and provides predefined responses based on the messages entered by the user.

## Features
- Responds to greetings such as hello, hi, and hey.
- Answers common questions such as "How are you?"
- Responds to thank-you messages.
- Recognizes goodbye messages.
- Provides a default response for unknown inputs.
- Continues the conversation until the user exits.

## Technologies Used
- Python
- Functions
- If-elif-else statements
- While loop
- User input and output

## How to Run
1. Open the project folder in VS Code.
2. Open `main.py`.
3. Open the terminal.
4. Run `python main.py`.
5. Enter messages and interact with the chatbot.
6. Type `bye` to end the conversation.

## Testing
Test the chatbot with greetings, common questions, unknown messages, and exit commands.
